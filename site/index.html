Como funciona

Você pede. O escritório resolve.

Cada escritório é um time com áreas e agentes, cada um com cargo, instruções e habilidades próprias. Um orquestrador coordena todo mundo.

Faça um pedido

Escreva o que precisa na barra de baixo, como falaria com uma pessoa. Dá para anexar imagens.

O orquestrador planeja

O ORCA escolhe quem resolve ou monta um plano em etapas entre as áreas: pesquisa, texto, revisão.

Os agentes trabalham

Você vê cada um se mexer nas mesas. Etapas independentes rodam ao mesmo tempo, e cada agente recebe o que veio antes.

Você aprova

A entrega final é consolidada e salva no Cérebro. Nada é enviado, publicado, pago ou apagado sem o seu OK.

Recursos

Tudo no escritório é seu para mudar.

Quantos times, quantas áreas, quantos agentes, como eles trabalham e até a cara de cada um.

Vários escritórios

Um time por assunto. Explique para que ele serve e a IA monta as áreas, os agentes e as primeiras habilidades.

Personalize tudo

Nome, cargo, instruções e aparência dos agentes; temas, cores, layout, sala e móveis do escritório.

Cérebro

As notas da sua empresa que os agentes leem antes de trabalhar. Cada entrega fica guardada lá.

Skills e lições

Ensine o jeito certo de fazer cada trabalho. Corrija uma entrega e marque "lembrar" para virar regra.

Rotinas

Tarefas automáticas todo dia, em dias úteis, toda semana ou a cada X minutos, com ou sem aprovação.

Seus conectores

Gmail, Slack, Notion e o que mais estiver no seu Claude. Você decide qual área usa cada um.

Projetos e GitHub

Agentes escrevem código no seu projeto, cada tarefa num branch separado. Aprovou, vira pull request.

Terminal embutido

Abas de terminal de verdade e o Claude Code interativo dentro do app, na pasta que você escolher.

Modelo certo para cada pedido

Pedidos simples vão para um modelo rápido e os complexos para o mais forte. Ou escolha à mão.

Instalação

Pronto em poucos minutos.

Baixe, instale e escolha o seu primeiro escritório. O app já vem com um time de exemplo para você testar.

O que você precisa

  • Mac com chip Apple (M1 ou mais novo) e macOS 12 ou superior, ou Windows 10/11 de 64 bits.
  • Claude Code instalado e logado. Rode claude uma vez no terminal. Se faltar, o próprio app oferece instalar.
  • Uma conta Claude com plano que inclua o Claude Code. O PJ Office usa o seu login e o seu plano.

  1. Baixe o arquivo .dmg

    Clique em Baixar para macOS no topo desta página.

  2. Arraste para Aplicativos

    Abra o arquivo baixado e arraste o ícone do PJ Office para a pasta Aplicativos.

  3. Libere a primeira abertura

    Abra o app. Se o macOS avisar que não pode verificar o desenvolvedor, vá em Ajustes do Sistema → Privacidade e Segurança, role até o aviso do PJ Office e clique em Abrir Mesmo Assim. Só é preciso fazer isso uma vez.

  4. Escolha seu escritório

    O tour guiado mostra o básico. Escreva seu primeiro pedido na barra e veja o time trabalhar.

  1. Baixe o instalador .exe

    Clique em Baixar para Windows no topo desta página.

  2. Execute o instalador

    Dê dois cliques no arquivo baixado. Se o Windows SmartScreen aparecer, clique em Mais informações → Executar assim mesmo.

  3. Prepare o computador

    Na primeira abertura, a tela Vamos preparar o seu PC confere o que falta: o Claude Code e o Git para Windows (o Claude Code usa o Git Bash para rodar comandos). Cada botão Instalar abre o instalador oficial no PowerShell; depois clique em Entrar para fazer login no Claude.

  4. Escolha seu escritório

    Abra o PJ Office pelo Menu Iniciar ou pelo atalho na Área de Trabalho, siga o tour e faça seu primeiro pedido. Ao fechar a janela, o escritório continua rodando no ícone perto do relógio.

Dúvidas

Perguntas frequentes

O PJ Office é pago?

O app é gratuito. A inteligência vem do Claude Code instalado no seu computador, então o uso conta no seu plano do Claude, como se você mesmo estivesse usando o Claude Code.

Meus dados vão para algum servidor do PJ Office?

Não. Escritórios, tarefas, conversas e o Cérebro ficam numa pasta do seu computador. Os pedidos vão direto do seu Claude Code para a Anthropic, com o seu login, como em qualquer uso do Claude.

Os agentes podem mandar e-mail ou publicar algo sozinhos?

Não sem você. Toda tarefa que envia, publica, paga ou apaga para em Aprovar com um rascunho, e só segue depois do seu OK.

Funciona em Mac com processador Intel?

Esta versão é para Macs com chip Apple (M1, M2, M3, M4 e mais novos).

Preciso saber programar?

Não. Você conversa com o escritório em português. Os recursos de código, terminal e GitHub estão lá para quem quiser, mas são opcionais.

Fechar a janela para o trabalho?

Não. Rotinas e tarefas continuam rodando em segundo plano, e você recebe uma notificação quando algo fica pronto ou precisa de aprovação.
