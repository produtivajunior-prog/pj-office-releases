# PJ Office — downloads

Instaladores do **PJ Office**: um escritório 3D de agentes de IA que trabalham para você, rodando no seu computador com o seu Claude Code.

Baixe a versão mais recente em **[Releases](../../releases/latest)**:

- **macOS** (Mac com chip Apple, M1 ou mais novo): `PJ-Office-<versão>-arm64.dmg`
- **Windows** 10/11 64 bits: `PJ-Office-<versão>-Setup-x64.exe`

Requer o [Claude Code](https://claude.com/claude-code) instalado e com login.
